# Paid Media Flashcards

Interview flashcards for B2B SaaS performance marketing (Google Ads and LinkedIn Ads). Plain static site for GitHub Pages: `index.html` plus the card data in `cards.js`. No build step, no service worker.

Add a card by appending an object to `cards.js`: `d` deck, `q` question, `s` answer to say out loud, optional `p` key points, `x` example, `n` prep note.
